# 실기기 검증 체크리스트 (Android · Chrome)

주소: **https://mrlee323.github.io/knittinglog/**

`main`에 푸시하면 GitHub Actions가 자동 배포한다. 배포 상태는
`gh run list --repo mrlee323/knittinglog`로 확인.

## 이미 검증된 것 — 다시 볼 필요 없음

로컬 프로덕션 빌드와 배포본에서 확인했다.

- 서비스워커 등록, 스코프 `/knittinglog/`
- 프리캐시 50개 + Pretendard 서브셋 런타임 캐시
- 딥링크(`/knittinglog/gauge/calc`) 라우팅, 404.html 폴백
- **서버를 완전히 죽인 상태**에서 새로고침 → 앱 전체 렌더
- 오프라인에서 프로젝트 생성 → 카운터 추가 → 7단 카운트 → 리로드 후 보존
- 설치 조건(HTTPS · SW · 192/512 아이콘 · standalone) 충족
- 매니페스트 scope/start_url/theme_color, apple-touch-icon 경로

## 실기기만 답할 수 있는 것

### 1. 설치

Chrome 메뉴 → **앱 설치** (또는 홈 화면에 추가).

설치를 누르면 **완료까지 1~2분 걸릴 수 있다.** 안드로이드는 설치 시 WebAPK를
구글 생성 서버에서 굽고 그 사이 알림이 조용하다. 아이콘이 바로 안 생겨도 실패가
아니므로 기다린다 — 실기기 검증에서 이걸 설치 실패로 오진한 적이 있다.

- [ ] 메뉴에 "앱 설치"가 보인다 — 안 보이면 설치 조건이 깨진 것
- [ ] 홈 화면 아이콘이 **검정 배경의 실타래**다 — 화면 캡처가 들어가면 아이콘 경로 문제
- [ ] 런처에서 아이콘이 잘리지 않는다 — 잘리면 maskable 안전영역 문제
- [ ] 앱을 열면 **주소창이 없다** (standalone) — 있으면 scope/start_url 불일치

### 2. 뜨기 모드 — 이 앱의 핵심 화면

프로젝트 만들고 카운터 추가 → 뜨기.

- [ ] +1 영역이 **엄지로 눌러서 편한 위치·크기**인가
- [ ] 연타할 때 화면이 확대되거나 텍스트가 선택되지 않는다
- [ ] 하단 시스템 내비게이션 바에 버튼이 가리지 않는다 (safe-area)
- [ ] **햅틱이 오는가** — Chrome Android는 `navigator.vibrate`를 지원하지만
      시스템 설정에서 진동을 끄면 안 온다. 안 오면 시스템 설정을 먼저 확인
- [ ] 1~2분 두고 봤을 때 **화면이 꺼지지 않는가** (Wake Lock)
      상단에 해 아이콘이 떠 있으면 잠금을 획득한 상태
- [ ] 홈으로 나갔다 돌아오면 해 아이콘이 다시 뜬다 (재획득)

### 3. 오프라인 — 비행기 모드

설치한 앱을 닫고 **비행기 모드를 켠 뒤** 앱 아이콘으로 실행.

- [ ] 앱이 정상 실행된다
- [ ] 카운터가 동작하고 값이 저장된다
- [ ] 앱을 완전히 종료하고 다시 열어도 단수가 남아 있다
- [ ] 한글이 Pretendard로 나온다 (시스템 폰트로 떨어져도 동작에는 문제 없음)

### 4. 실제로 뜨면서 써보기

여기서 나오는 게 제일 중요하다. 아래는 의심되는 지점.

- [ ] 한 손으로 카운터를 누르며 뜰 수 있는가
- [ ] 화면을 안 보고 눌러도 눌린 걸 아는가
- [ ] 실수로 두 번 눌렀을 때 되돌리기를 찾기 쉬운가
- [ ] 생명줄 문구("N단만 풀면 돼요")가 실제로 도움이 되는가
- [ ] 연동 카운터가 기대대로 오르는가

## 문제가 나오면

배포본 콘솔은 Chrome 데스크톱에서 **원격 디버깅**으로 본다:
`chrome://inspect` → 폰을 USB로 연결 → 대상 선택.

캐시가 꼬였을 때는 앱 설정에서 저장 공간을 지우거나,
Chrome에서 사이트 데이터를 삭제하고 다시 설치한다.
`registerType: "autoUpdate"`이므로 새 배포는 다음 실행에서 자동 반영된다.

## 공유 시트 (안드로이드)

Web Share Target은 **설치된 PWA에서만** 동작한다. 브라우저 탭으로 열어둔
상태에서는 공유 시트에 뜨지 않으므로, 아래 순서를 지켜야 한다.

- [ ] 앱을 설치한다 (Chrome 메뉴 > 앱 설치). WebAPK 생성에 1~2분 걸린다.
- [ ] 핀터레스트나 갤러리에서 **공유하기** > 목록에 knittinglog가 뜨는지
- [ ] 이미지를 공유했을 때 보관함에 카드가 생기는지
- [ ] 링크를 공유했을 때 주소가 살아 있고 눌러서 열리는지
      (앱이 `url`을 비우고 `text`에 함께 담아 보내는 경우가 흔하다 —
      그때도 주소가 뽑히는지가 요점이다)
- [ ] 연달아 두 번 공유했을 때 둘 다 들어오는지 (하나가 대체되면 알려야 한다)
- [ ] 공유한 직후 화면이 보관함으로 넘어가고 "N개를 넣었어요"가 뜨는지

iOS는 공유 시트 대상이 되지 않는다. 보관함 화면의 주소 붙여넣기로 대체된다 —
그 경로가 손에 맞는지도 함께 본다.
